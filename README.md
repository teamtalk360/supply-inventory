# Supply Inventory

A barcode inventory app for a vascular surgery office-based lab. Open it in Safari on an iPhone (or any modern browser). Your inventory stays on the device; nothing is uploaded unless you turn on a Google Sheets backup yourself.

**Open the app:** https://teamtalk360.github.io/supply-inventory/

## First time on iPhone

1. Open the link in **Safari** (not Chrome). Safari will show a lock / “https” — this site uses a trusted certificate.
2. When asked, **Allow Camera** so you can scan package barcodes.
3. Tap the **Share** button, then **Add to Home Screen**. Opening it from the Home Screen works more like an app and is more reliable offline after the first load.
4. The first visit downloads about 2 MB (the page plus the barcode engine). After that it can work without a network.

## What stays private

Counts, lot numbers, and scans are stored only in this phone’s browser storage. They are not on GitHub and are not sent anywhere unless you export a file or set a Sheets webhook. Back up from the app’s Export / Share buttons if you clear Safari data or get a new phone.

The public site only contains the app itself and a starter catalog of two example products (no stock). Do not publish photos of real labels or patient information.

## Desktop or USB scanner

You can also open the same address on a computer and type or scan into the scan box with a USB or wireless “keyboard wedge” barcode scanner.
